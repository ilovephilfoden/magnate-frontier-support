プライバシーポリシー

MAGNATE FRONTIER

制定日: 2026年6月2日 / 最終改定日: 2026年9月13日

本ポリシーは、スマートフォン向けカードゲーム「MAGNATE FRONTIER」における情報の取り扱いについて説明するものです。

取得する情報

本アプリは、現時点で利用者の氏名、住所、電話番号、メールアドレスをアプリ内で入力させる機能を持ちません。

オンライン対戦機能を提供するため、Unity Gaming Servicesを利用します。この際、匿名ユーザーID、接続情報、部屋作成・参加に必要な技術情報、対戦中のゲーム進行データなどがUnity側で処理される場合があります。

表示名、Game Center連携状態、端末とOSの情報、IPアドレス、接続・エラー記録、対戦・ルーム・フレンド情報、進行・所持品を、認証、オンライン機能、保存・復旧のために取得または処理する場合があります。ゲーム進行と結果、課金残高・権利には運営者の権限サーバーでの処理と保存も含まれます。

フレンド機能では表示名、関係情報、オンライン状態などを扱います。お問い合わせで利用者が任意に送信した内容は対応のために扱います。公開の問い合わせ欄には、個人情報、アカウントや端末の識別情報、部屋番号、招待情報、購入明細を書かないでください。

アプリ内課金では、購入内容の検証、付与、復元、二重付与防止のため、商品ID、StoreKit取引ID、購入日時、購入環境、権利状態、匿名ユーザーIDとの対応を処理します。クレジットカード番号などの決済手段情報はAppleが取り扱い、本アプリおよび本アプリの権限サーバーでは取得しません。

Unity IAPでは、アプリのインストールや端末を識別する情報、端末・OS・アプリの情報、セッション、認証完了や購入操作に関するイベント、購入失敗の理由・詳細がUnityへ送信される場合があります。これらは専用の分析サービスの設定とは別に処理されます。

利用目的

  • オンライン対戦の部屋作成、参加、通信接続の維持
  • フレンド関係とオンライン状態の表示
  • ゲーム進行・所持品・対戦結果の保存と復旧
  • 利用者からの問い合わせへの対応
  • 不具合の調査とサービスの安定運用
  • 不正利用や通信上の問題の確認
  • アプリ内課金の検証、購入商品の付与、復元、二重付与の防止

利用する第三者サービス

  • Unity Authentication
  • Unity Relay
  • Unity Friends
  • Unity Multiplayer / Netcode関連機能
  • Unity Cloud Code
  • Unity IAP
  • Apple StoreKit
  • Apple Game Center
  • Google Gmail（個別サポートのメール受付）

各サービスにおける情報の取り扱いは、Unity Technologiesの規約およびプライバシーポリシー、Unity IAPのデータ説明も参照してください。

メールでの個別サポートにはGoogle Gmailを使用します。返信先や問い合わせ本文は同サービスで処理されます。Googleのプライバシーポリシーも参照してください。

広告とアプリ内課金

初期リリース時点では広告を使用しません。Appleのアプリ内課金により、消費型のマグコインと非更新型のシーズンパスを販売します。購入価格はAppleの購入画面に表示され、ゲーム内通貨およびデジタル商品は換金できません。今後、広告、分析、クラッシュレポートなどを追加する場合は、本ポリシーとApp Store上の表示を更新します。

子ども向けの扱い

本アプリは、現時点では子ども専用アプリとして設計していません。年齢制限や子ども向け該当性は、App Store Connect上でゲーム内容と機能に合わせて設定します。

アカウント削除後の保存方針

アカウント削除時は、ゲームの本人情報・進行・所持品を削除します。返金対応と購入の重複付与防止に必要な最小限の取引記録は、ゲームの本人情報とのひも付けを外して削除後1年間保存し、その後削除します。税務上必要な売上明細などは、別途法令に従って保存します。1年間は本サービスの運用上の保存期間です。

サーバーログとバックアップの保存

サーバー基盤であるRailwayが保存するアプリケーション・配備・ビルド・HTTP・PostgreSQLのログは、Railwayへの取り込みから90日間保存された後に削除されます。これらのログは、アカウント削除の申請に応じて特定の記録だけを先に消すことができません。日次バックアップの保存期間は6日間です。手動で作成したバックアップには自動の保存期限がないため、別途削除の管理が必要です。

問い合わせ記録の保存

問い合わせ記録は、対応終了から6か月で削除します。法令上保存が必要な記録は必要な範囲に限定し、残す対象と理由を説明します。
